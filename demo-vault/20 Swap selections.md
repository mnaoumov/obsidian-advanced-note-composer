# Swap selections

Exchange two pieces of selected text in one step - within one note or across two notes. This is the
text-level counterpart to [07 Swap file](<./07 Swap file.md>) (whole notes) and [08 Swap folder](<./08 Swap folder.md>) (whole folders).

## Try it (within one note)

1. Select the word **alpha** in the line below.
2. Run `Swap selections: Mark selection to swap`.
3. Select the word **omega** in the same line.
4. Run `Swap selections: Swap with marked selection`.
5. The two words trade places: `alpha ... omega` becomes `omega ... alpha`.

Swap alpha with omega right here.

## Try it (across two notes)

1. Mark a selection in this note with `Swap selections: Mark selection to swap`.
2. Open another note, select some text there, and run
   `Swap selections: Swap with marked selection`.
3. The two selections are exchanged between the notes.
