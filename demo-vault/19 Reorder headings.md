# Reorder headings

Reorder a note's **top-level sections** without cutting and pasting. Each top-level heading and
everything under it (including nested subheadings) moves as one block.

## Try it

1. Put the cursor anywhere in this note.
2. Run `Reorder headings...`.
3. In the dialog, use the up/down arrows to move a section - for example, move `Beta` above `Alpha` -
   then click **Reorder**.
4. The three sections below are rewritten in the new order; any content before the first heading (the
   preamble) stays put.
