# Include and exclude

Two independent path filters decide where this plugin operates. One says what it may **touch** — as a
picker entry, a merge target, or something a folder operation is allowed to move. The other says where
its commands are **offered** at all. Keeping them apart is what lets you hide the commands in a folder
you still merge into, or protect a folder whose commands you want to keep.
