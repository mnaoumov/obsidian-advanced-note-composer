Welcome to the [Advanced Note Composer](https://github.com/mnaoumov/obsidian-advanced-note-composer/) demo vault. Each note below walks through one feature - open it, follow the steps, and watch the plugin work.

> [!TIP] Interactive buttons
>
> Some notes have **Run** buttons that flip a plugin setting for you. They are powered by [`CodeScript Toolkit`](https://github.com/mnaoumov/obsidian-codescript-toolkit/), which this vault installs for you automatically on first open. Every note also spells out the manual equivalent, so you never strictly need it.
