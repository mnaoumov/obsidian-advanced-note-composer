# Merge

Merging takes the content of one thing and folds it into another, then deletes what it emptied. The
four notes here go from the simplest case — this note into that one — up to collapsing a whole folder
tree into a single file. All of them share one pipeline, so the template, frontmatter strategy,
footnote renumbering and link fixing you configure once apply to every one of them.

| Note | What it covers |
| --- | --- |
| [01 Merge file](<./01 Merge file.md>) | One note into another, and the attachments that follow it |
| [02 Merge folder](<./02 Merge folder.md>) | A folder's notes into another folder, keeping the structure |
| [03 Merge folder into single file](<./03 Merge folder into single file.md>) | A whole folder tree collapsed into one note, optionally with folders as headings |
| [04 Merge multiple files](<./04 Merge multiple files.md>) | Several notes selected in the file explorer, merged in one go |
