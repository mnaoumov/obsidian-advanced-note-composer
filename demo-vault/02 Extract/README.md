# Extract

Extracting is the opposite of merging: it takes part of a note out into a note of its own. What you can point at varies — a selection, a whole heading with everything under it, the block between two horizontal rules — but the machinery is the same, and so is the question of what to leave behind in its place.

| Note | What it covers |
| --- | --- |
| [05 Extract selection](<./05 Extract selection.md>) | The selected text, the text before or after the cursor, and extracting into the same note |
| [06 Extract heading](<./06 Extract heading.md>) | A heading and its whole section, from anywhere inside it, or only its content with the heading left in place |
| [07 Text after extraction](<./07 Text after extraction.md>) | What replaces the text you moved: a link, an embed, or nothing |
| [08 Extract between horizontal rules](<./08 Extract between horizontal rules.md>) | The block between the rules nearest the cursor — no selecting, which suits mobile |
| [37 Create empty note](<./37 Create empty note.md>) | Extracting NOTHING: an empty note plus a link at the cursor, from the editor or the file explorer |
| [44 Extract attachment into its own note](<./44 Extract attachment into its own note.md>) | An embedded attachment into a note of its own, with every `[[parent#^block]]` link moved to that note |
| [46 Move selection under heading](<./46 Move selection under heading.md>) | A selection, or a marked smart cut & paste selection, under a heading chosen in any note, without opening it |
